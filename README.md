# 《桌面西装小人》桌宠

一个以用户形象为原型的桌面宠物：穿西服的小人在屏幕底部来回走动，点击它会挥手、跳跃、说话，可以拖拽，右键有菜单。

## 运行

需要 Python 3 + Pillow：

```
pip install pillow
pythonw desk_pet.py
```

双击 `启动桌宠.vbs` 可静默启动（该脚本里的路径是本机生成的示例路径，可自行改成自己的 pythonw 路径）。

## 功能

- 屏幕底部自动左右走动，步伐走-立-走-立循环，随机停歇
- 单击：随机触发挥手 / 跳跃 / 说话
- 拖拽：按住可拖动到任意位置
- 右键菜单：打个招呼、跳一个、说句话、原地站定/继续走、退出
- 角色精灵图在 `sprites/`：stand / walk1 / walk2 / wave / jump

## 技术

纯 Python tkinter，无框架，Pillow 处理透明 PNG 精灵图。动画帧间隔 `TICK` 可调（越小走得越快）。
